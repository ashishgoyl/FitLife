# FitLife Backend REST API Documentation

The FitLife backend runs on `http://localhost:5001` (or the port defined by `process.env.PORT`) and handles AI coaching, SMS/WhatsApp OTP dispatches, and configuration synchronization.

All endpoints support CORS and return standard JSON responses.

---

## 1. AI Health Coach

### `POST /api/ai-coach`
Generates personalized wellness feedback based on the user's logged habits for the day.

#### Request Headers
```http
Content-Type: application/json
```

#### Request Body
```json
{
  "profile": {
    "username": "Ashish",
    "goal": "lose",
    "targetCalories": 1800,
    "targetProtein": 120,
    "waterTarget": 2500,
    "sleepTarget": 8
  },
  "meals": [
    {
      "name": "Moong Dal Khichdi",
      "calories": 320,
      "protein": 14,
      "carbs": 48,
      "fat": 6,
      "mealType": "lunch"
    }
  ],
  "exercises": [
    {
      "name": "Brisk Walk",
      "durationMins": 30,
      "sets": 0,
      "reps": 0
    }
  ],
  "waterMl": 1500,
  "sleepHours": 7.5
}
```

#### Successful Response (`200 OK`)
```json
{
  "advice": "🌟 **Daily Health Coach Summary for Ashish**\n\n• 🔥 **Calorie Balance:** Great calorie deficit pacing for fat loss!...",
  "source": "gemini",
  "model": "gemini-3.1-flash-lite"
}
```
*Note: If the Gemini API key is missing or quota is exceeded, `source` returns `"builtin"` with guidance generated by FitLife's built-in heuristics engine.*

## 2. Multi-Provider OTP Dispatch

### `POST /api/send-otp`
Sends a one-time verification password to a 10-digit mobile number across supported SMS/WhatsApp gateways.

#### Request Body
```json
{
  "phoneNumber": "9876543210",
  "otp": "481920",
  "channel": "whatsapp",
  "provider": "callmebot",
  "settings": {
    "callmebotKey": "your_callmebot_key"
  }
}
```

#### Supported Providers:
- `callmebot`: Free developer WhatsApp API
- `twilio`: Official WhatsApp & SMS dispatch
- `fast2sms`: Indian DLT/Quick SMS Gateway
- `rapidapi`: Global SMSAPI gateway

#### Successful Response (`200 OK`)
```json
{
  "success": true,
  "message": "OTP sent via WhatsApp to +91 9876543210"
}
```

## 3. Google Client ID Configuration

### `GET /api/google-client-id`
Retrieves the active Google OAuth 2.0 Client ID configured in the server environment.

#### Response (`200 OK`)
```json
{
  "clientId": "your_google_client_id.apps.googleusercontent.com"
}
```

---

### `POST /api/google-client-id`
Dynamically updates the Google OAuth 2.0 Client ID and writes it to `.env`.

#### Request Body
```json
{
  "clientId": "new_client_id.apps.googleusercontent.com"
}
```

#### Response (`200 OK`)
```json
{
  "success": true,
  "clientId": "new_client_id.apps.googleusercontent.com"
}
```

## 4. Health Check

### `GET /api/health`
Verifies backend server health and uptime.

#### Response (`200 OK`)
```json
{
  "status": "ok",
  "timestamp": "2026-11-10T09:12:00.000Z"
}
```
